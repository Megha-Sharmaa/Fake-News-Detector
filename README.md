# 📰 Fake News Detector

A Streamlit web app that detects whether a news headline/article is **REAL ✅** or **FAKE 🚨** using the ISOT dataset.

## 🚀 Features
- Paste any headline/article and get instant prediction
- Confidence scores with bar chart + progress bar
- Model performance metrics (accuracy, recall, precision)
- Clean, emoji-rich UI
- Sidebar with quick demo headlines
